// mission

Build the fastest, most private way to use the useful web without leaving the terminal — a focused session client for people (and later agents) who refuse full-browser bloat.

For developers and terminal-native people who need to search, open, and read without context-switching,
browse is a private, ultra-fast terminal web session
that delivers structured pages, DuckDuckGo search, and a local Start Page
because we never run a browser engine — only what you need to stay in flow.

// never promise

Replaces Chrome. Works on every site. Solves CAPTCHAs. Pixel-perfect pages. “India’s Google.”

// who it is for

People who live in tmux, SSH, and a text editor. Docs, blogs, HN, Wikipedia, public HTML. Agents who want the same document as JSON via browse snapshot.
