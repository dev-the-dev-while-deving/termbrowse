a terminal web session · structure first · no Chrome

// what this is

Search, open, read, and save the useful web without leaving the shell. HTML becomes a structured document, then a 256-color layout that reflows with your terminal. Sites keep a little identity. No page JavaScript. No browser engine.

URL → fetch → roles + identity → layout(width) → terminal

// get it

$ curl -fsSL https://raw.githubusercontent.com/dev-the-dev-while-deving/termbrowse/from-scratch/install.sh | sh
$ browse
fast

One binary. Zero Chromium. Start Page is local. Docs feel instant.

private

No arbitrary site JS. Bookmarks stay on disk. No telemetry by default.

focused

DuckDuckGo only. Keyboard session. Chrome for apps — browse for reading.

macOS (Apple Silicon + Intel) and Linux (x86_64 + ARM). Then browse update when we ship.
