// install

One curl. No Rust. macOS (Apple Silicon or Intel) and Linux (x86_64 or ARM). Writes ~/.local/bin/browse.

01 fetch the binary

$ curl -fsSL https://dev-the-dev-while-deving.github.io/termbrowse/i | sh

02 if the shell cannot find it

$ export PATH="$HOME/.local/bin:$PATH"

03 use it

$ browse
$ browse https://example.com
$ browse update

// from source

$ cargo run --release
The binary is unsigned. browse checks GitHub at most once per day for a newer version and never sends page or search data.
Curl install needs a published GitHub Release (v0.1.0 tag). Until then, use cargo from the repo.
re-run the curl or type browse update source
